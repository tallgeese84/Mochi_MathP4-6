      Learning evidence & target

      September 2027 is a planning target, not a confirmed test date. NUS High uses a separate DSA route that starts earlier; English needs separate preparation. The classroom teaches Maths and Science before its checks; completion records exposure, not mastery.

      Science learning and investigations

      Progress stays on this device. Back it up to move devices; backups contain learning notes, never API keys.

      Independent assessment record

      Use unfamiliar, externally marked assessments to judge the top 1% ambition. App accuracy cannot establish a percentile.

      Legacy accuracy by topic

      Older totals include helped answers; they are not used as evidence of independent learning.

      Build

      How it works. Every question, its answer and its working are generated in JavaScript and appear instantly. The cat is handed all three and only does the talking — he never marks and never calculates, and he is never on the path between tapping Next and seeing the question. If the network drops, the hints, bar models and working still run.
